
# ⚔️ AI Chat Arena

AI Chat Arena is a web-based platform where users can input a coding or technical problem and compare responses from multiple AI models side-by-side.

It helps developers evaluate different AI solutions and understand which one performs better in terms of accuracy, clarity, and real-world applicability.

---

## 🧠 Key Features

- 🔍 Ask any coding or technical question
- 🤖 Compare responses from multiple AI models
- ⚖️ Side-by-side solution comparison
- 🧾 Highlighted code blocks for better readability
- 🏆 Judge-based scoring system for best solution
- ⚡ Fast and responsive UI using React

---

## 🛠️ Tech Stack

### Frontend
- React (Vite)
- Tailwind CSS
- Axios
- React Markdown + Highlight.js

### Backend
- Node.js + Express
- LangChain Integration
- Multiple AI providers (Cohere, Google, Mistral)
